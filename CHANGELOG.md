# Changelog

All notable changes to GielisMeta-CST will be documented in this file.

## [1.0.0] - 2026-08-28

### Added

- MATLAB App Designer interface for Gielis-inspired structures.
- Absorber, transmitter, and sensor operating modes.
- Conventional and complementary concentric geometries.
- Automated CST model construction, excitation, boundaries, and simulation.
- Absorption and S-parameter postprocessing.
- Optional electric- and magnetic-field monitor generation.
- English user manual and software citation metadata.
