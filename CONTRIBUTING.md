# Contributing

Contributions that improve compatibility, geometry handling, validation, documentation, or postprocessing are welcome.

1. Open an issue describing the proposed change or defect.
2. Create a branch from `main`.
3. Keep `GielisMetaCST.mlapp`, `CST_MicrowaveStudio.m`, and `macros/` compatible.
4. Test changes on Windows with licensed MATLAB and CST Studio Suite installations.
5. Do not commit generated CST projects, solver outputs, proprietary vendor files, credentials, or personal absolute paths.
6. Submit a pull request describing the tested MATLAB/CST versions and the observed result.
