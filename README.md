# Examples

The illustrated validation workflows are provided in the user manual:

1. Periodic absorber with absorption postprocessing.
2. Transmissive conventional or complementary structure with S21 postprocessing.
3. Microstrip sensor with complementary Gielis-CSRR ground and field monitoring.

To reproduce a case, launch `GielisMetaCST.mlapp`, enter the parameters shown in the corresponding manual figure, and follow the mode-specific workflow.

Generated CST projects are intentionally excluded from version control because they depend on proprietary CST Studio Suite software and may be large. Reusable numerical exports may be added here in future tagged releases.
