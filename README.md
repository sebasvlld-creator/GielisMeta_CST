# GielisMeta-CST

GielisMeta-CST is a MATLAB App Designer tool for the automated design, construction, simulation, and postprocessing of Gielis-inspired microstrip electromagnetic structures in CST Studio Suite.

The application provides a single graphical workflow for three operating modes:

- **Absorber:** periodic, ground-backed structures evaluated through absorption.
- **Transmitter:** periodic transmissive structures evaluated through S-parameters.
- **Sensor:** complementary Gielis-CSRR structures coupled to a microstrip line.

## Main features

- Parametric Gielis-curve generation from `a`, `b`, `m`, `n1`, `n2`, and `n3`.
- Radial-envelope reconstruction for CST-compatible polygons.
- Conventional and complementary concentric structures.
- Automatic creation of substrates, conductors, ports, boundaries, and monitors in CST.
- Mode-dependent postprocessing of absorption and transmission responses.
- Optional electric- and magnetic-field monitors at a selected frequency.

## Requirements

- 64-bit Microsoft Windows. The MATLAB-CST link uses ActiveX/COM automation.
- MATLAB with App Designer support.
- CST Studio Suite with a valid license.

The reference environment used for the accompanying manuscript and manual was:

- Windows 11 Pro, 64-bit
- MATLAB R2026a
- CST Studio Suite 2025

Other recent versions may work, but have not been validated by the authors.

## Installation

1. Download the latest repository release or select **Code > Download ZIP**.
2. Extract the complete archive without changing its directory structure.
3. Open MATLAB on a Windows computer with CST Studio Suite installed.
4. Set the repository root as the MATLAB current folder, or add it to the MATLAB path:

   ```matlab
   addpath(genpath('path_to_GielisMeta-CST'))
   ```

5. Open `GielisMetaCST.mlapp` in MATLAB App Designer and click **Run**.

At the first CST connection, `CST_MicrowaveStudio.m` installs the required `.mcr` files into CST's `CST_App Macros` directory.

## Basic workflow

1. Select **Absorber**, **Transmitter**, or **Sensor**.
2. Enter the Gielis parameters and click **Preview**.
3. Configure the substrate, metal, materials, and gap.
4. Click **Generate** and inspect the concentric structure.
5. Adjust size, rotation, and - in sensor mode - displacement and line width.
6. Define the frequency range.
7. Click the mode-specific **Build** button to create the CST model.
8. Confirm the simulation checklist and click **Simulate**.

See [`docs/GielisMeta-CST_User_Manual.pdf`](docs/GielisMeta-CST_User_Manual.pdf) for the complete illustrated procedure.

## Reproducibility notes

- CST project files are not included because they are generated by the application and depend on proprietary CST Studio Suite software.
- Generated `.cst` projects and solver outputs are ignored by Git by default.
- Numerical results can vary with CST version, meshing, solver settings, and hardware.
- The example values in the manual are validation cases, not universal optimized designs.
